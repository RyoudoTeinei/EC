# Assignment Extension

## When this applies
You need extra time to submit a single assessment for a reasonable cause: short illness, family event, technical issues, workload clash, etc.

## Key rules
- **Who approves.** Your course convener approves extensions, not the College.
- **How to apply.** Most courses use **Wattle → Assessment item → Request Extension**. If that option is missing, email the convener directly.
- **Apply early.** Always before the due date. Late requests are usually refused — you would need to go through Special Consideration instead.
- **Length.** 1–7 days is generally easy to justify with a short reason. Longer extensions usually require supporting documentation.
- **Evidence.** Short extensions with a plausible reason often need no document. Long or repeat extensions normally need a medical certificate or equivalent.

## If the convener does not respond
- Wait 24 hours, then resend and CC the course administrator.
- Still no reply → contact the College's Student Administration; they have an escalation path.
- Less than 24 hours to deadline → **submit what you have**. A partial submission with a covering note is much better than zero.

## Wattle has no extension button
- The course has not enabled self-service extensions → email the convener directly.
- Include in the email:
  - Student ID + course code + assessment name.
  - The exact new date you are requesting (not "a few days").
  - A short reason — one or two sentences.
  - Any supporting document, if you have one.

## Don't
- Don't submit late and ask afterwards — most conveners will not retroactively approve.
- Don't write a long story — conveners process many of these per day; brevity helps.
- Don't fabricate documentation. Academic misconduct consequences are severe.

## Email template
```
Subject: Extension request — [COURSE CODE] [Assessment name]

Dear [Convener name],

I am writing to request a [N]-day extension for [Assessment name] in
[COURSE CODE], currently due [original date]. I would like to submit by
[new date].

[One-sentence reason. e.g., "I have been unwell since [date] and have
attached a medical certificate."]

Please let me know if you need any further information.

Thank you,
[Your name]
[Student ID]
```
